# P-12 retryPayment and reauthorizePayment cannot be a no-op when there is no Payment

status: open
found by: T-80, implementer (claude opus), 2026-11-18 (from review-S2 SHOULD FIX T-56/T-57)
flow: place-order-flow
blocks: T-80 (only its "no-op when no Payment exists" part; the rest of T-80 is done)

## Problem
Both commands say "No-op unless FAILED and input.attemptCount == attemptCount"
([payments-processing-domain-model.zdl:131](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L131),
[:141](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L141)), so no Payment should be a
no-op too, as for voidPayment
([:157](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L157)). But they return a non-null
`Payment`
([:138](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L138),
[:147](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L147)), while voidPayment returns
`Payment?` ([:163](../../../arcadia-editions-modulith-api/payments-processing-domain-model.zdl#L163)). The generated
(always) `PaymentsProcessingService` interface has `fun retryPayment(...): Payment` and `fun reauthorizePayment(...): Payment`,
so the implementation has nothing to return for a missing Payment and throws `NoSuchElementException`. The listener
publication then stays incomplete and is replayed on every restart (review-S2: 32 NoSuchElementException from stale
PaymentRetried publications).

## Evidence
- `PaymentsProcessingServiceTest.retryPaymentNotFoundTest`, `.reauthorizePaymentNotFoundTest` assert the throw.
- Returning a non-saved placeholder `Payment()` would work around the signature in code; not done.

## Options
- A: `retryPayment(RetryPaymentInput) Payment?` and `reauthorizePayment(ReauthorizePaymentInput) Payment?`, comments
  "No-op, no event, when there is no Payment or ..." as voidPayment. Changes: the ZDL (2 lines + comments); regenerate
  the service interface; the impl returns null and logs; the two NotFound tests assert null and no event. No test data change.
- B: keep `Payment` and keep the throw (a missing Payment is a bug, let the publication stay incomplete). Changes:
  none; the replay of stale publications stays.

Recommendation: A, matches voidPayment and the "No-op unless" wording, and stops the endless replay.
